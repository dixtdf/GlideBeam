# GlideBeam 1.0.0 / 光梭

## 中文

本版新增 Windows Setup 安装程序，提供 x64、ARM64 两个版本，同时保留四架构便携 ZIP。Mac 主机继续使用 ZIP 分发。音频、低延迟调度和阶段诊断沿用 0.3.0；从 0.2.1 升级时请同时更新双端。

- Windows 安装向导支持简体中文和 English，仅为当前用户安装到 `%LOCALAPPDATA%\Programs\GlideBeam`，无需管理员权限。
- 提供开始菜单快捷方式、可选桌面快捷方式，以及 Windows「已安装的应用」卸载入口。交互安装完成后可选择启动；静默安装不会启动客户端。
- 运行新版 Setup 即可升级。升级和卸载保留 `%LOCALAPPDATA%\RemoteNative` 中的设置与配对资料；不把私人配置打进安装包。
- Setup 使用与对应便携 ZIP 相同的程序文件、公开文档和第三方许可。构建锁定 Inno Setup 6.7.3 并验证依赖摘要；发布清单覆盖四个 ZIP 与两个 Setup EXE。
- x64 CI 检查隔离目录中的安装、同版本修复、卸载、文件摘要、快捷方式、卸载登记与配置保留；ARM64 在 x64 构建机上检查产物，未执行 ARM64 客户端。

1.0.0 是安装与发布方式的里程碑，不表示稳定 60 FPS 已验收。参考 RTX 3060 / macOS 15.8.1 环境在已有测试负载下，独立采集约 51–55 Complete/秒；可听音质、捕获至扬声器端到端延迟，以及 Windows ARM64 / Apple Silicon 实体配对会话仍未验收。详见[兼容性](../compatibility.md)、[音频说明](../audio.md)与 [FPS 稳定性记录](../fps-stability-2026-10-12.md)。本版不更新显卡驱动。

## English

This release adds Windows x64 and ARM64 Setup installers while retaining all four portable ZIPs. Mac hosts continue to ship as ZIPs. System audio, low-latency scheduling and stage diagnostics carry over from 0.3.0; update both endpoints when upgrading from 0.2.1.

- English/Simplified Chinese Setup installs for the current user into `%LOCALAPPDATA%\Programs\GlideBeam`, without administrator privileges.
- Setup creates a Start menu shortcut, offers an optional desktop shortcut, and registers an uninstaller in Windows Installed apps. Interactive setup offers a launch checkbox; silent installation does not launch the client.
- Run a newer Setup to upgrade. Upgrade and uninstall preserve settings and pairing data in `%LOCALAPPDATA%\RemoteNative`; private configuration is excluded from the payload.
- Setup uses the same application files, public documentation and third-party notices as its corresponding portable ZIP. The compiler is pinned to Inno Setup 6.7.3 with verified dependency hashes. The release checksum manifest covers four ZIPs and two Setup EXEs.
- x64 CI checks isolated install, same-version repair and uninstall, installed hashes, shortcuts, uninstall registration and configuration retention. ARM64 artifacts are built and checked on x64 without executing the ARM64 client.

Version 1.0.0 marks the installer and release milestone. Stable 60 FPS remains unverified; independent capture on the reference RTX 3060 / macOS 15.8.1 setup measured approximately 51–55 Complete events per second under the observed test load. Listening quality, capture-to-speaker latency, and physical Windows ARM64 / Apple Silicon paired sessions remain unvalidated. See [compatibility](../compatibility.md), [audio](../audio.md) and the [FPS experiments](../fps-stability-2026-10-12.md). This release makes no graphics driver changes.

Verify the selected download against `SHA256SUMS.txt`. Windows apps and installers are unsigned. Mac apps are ad-hoc-signed without Developer ID signing or notarization; macOS may request permission approval after replacement. Configuration paths and pairing formats remain compatible. Credentials, logs, signing keys, BlackHole and the experimental NVIDIA driver are not bundled.
