# GlideBeam 1.1.0 / 光梭

## 中文

本版集中改进 Windows 客户端的常驻、任务栏固定和更新体验，不改变远控协议、视频格式或显卡驱动。Mac 主机仅同步版本号。

- **右下角托盘**：左键单击切换主窗口显示与隐藏，隐藏不会断开远程会话；右键菜单提供打开、隐藏和退出，Explorer 重启后会恢复图标。
- **稳定任务栏身份**：进程和安装快捷方式统一使用 `dixtdf.GlideBeam` AppUserModelID。第二次启动会激活并复用已有窗口，不再创建另一个主窗口，便于固定到任务栏。旧版固定图标建议重新固定一次。
- **默认地址**：新配置默认使用 `127.0.0.1:47990`；远程连接仍应填写 Mac 的局域网地址。已保存的连接地址不会被改写。
- **软件内更新**：「偏好设置 → 软件更新」可手动检查 GitHub 最新正式版，按当前 Windows 架构下载对应 Setup，并使用同一 Release 的 `SHA256SUMS.txt` 校验。安装前会再次核对文件摘要。
- **安装行为**：更新包保存在 `%LOCALAPPDATA%\GlideBeam\updates`。启动 Setup 后当前客户端有序断开并退出；Setup 也会自动关闭占用目标文件的进程。升级保留 `%LOCALAPPDATA%\RemoteNative` 中的配对与设置，更新完成后需要重新打开应用。
- Windows 程序和 Setup 尚未进行 Authenticode 签名；HTTPS 与同 Release 校验和用于完整性检查，不等同于发布者签名验证。

验证包括 x64 GCC 完整原生回归、更新器离线语义与 Release/清单测试、真实 GitHub 查询及 Setup 下载校验、安装/修复/卸载与快捷方式 AppUserModelID 检查，以及隔离目录中的运行中客户端自动关闭测试。ARM64 仅完成交叉构建和静态 PE 检查，未在实体设备执行。托盘显隐与第二实例复用窗口由原生消息自检覆盖，实际双开进程测试亦通过。

本版不承诺稳定 60 FPS，不新增 HEVC、公网中继或登录前控制；实体 ARM64 / Apple Silicon 配对会话和可听音质仍未验收。详见[兼容性](../compatibility.md)、[构建说明](../building.md)与[发布自动化](../release.md)。

## English

This release improves Windows background operation, taskbar pinning and updates. It does not change the remote protocol, video format or graphics driver. The Mac host only receives the matching version metadata.

- **Notification area**: left-click toggles the main window without disconnecting the remote session. The right-click menu provides open, hide and exit, and the icon is restored after Explorer restarts.
- **Stable taskbar identity**: the process and installed shortcuts use `dixtdf.GlideBeam` as their AppUserModelID. Launching again activates the existing window rather than creating another main window. Repin shortcuts created by older versions once.
- **Default address**: new configurations default to `127.0.0.1:47990`. Use the Mac's LAN address for a remote session; saved addresses are not rewritten.
- **In-app updates**: **Preferences → Software updates** checks the latest stable GitHub release on demand, downloads the Setup for the current Windows architecture, and verifies it against the same release's `SHA256SUMS.txt`. The file is hashed again before installation.
- **Install behavior**: downloads remain in `%LOCALAPPDATA%\GlideBeam\updates`. The client disconnects and exits after starting Setup, and Setup also closes processes holding the target files. Pairing and settings in `%LOCALAPPDATA%\RemoteNative` are preserved. The application is not automatically restarted.
- Windows applications and Setup are not Authenticode-signed. HTTPS and same-release checksums provide integrity checks, not publisher signature verification.

Validation includes the full native x64 GCC regression suite, offline updater/version/release/manifest tests, a real GitHub release query and verified Setup download, install/repair/uninstall and shortcut AppUserModelID checks, and automatic closure of a running client in an isolated installation. ARM64 is cross-built and statically checked but not executed on a physical device. Tray toggling and single-instance reuse are covered by native message tests and an actual two-process launch test.

This release does not claim sustained 60 FPS, HEVC, an Internet relay or login-screen control. Physical ARM64 / Apple Silicon paired sessions and listening quality remain unvalidated. See [compatibility](../compatibility.md), [building](../building.md) and [release automation](../release.md).
