# GlideBeam 0.3.0 / 光梭

## 中文

本版将 Mac 系统声音传输、视频调度优化和阶段诊断带入正式安装包。请同时更新 Mac 主机与 Windows 客户端。

- 系统音频：5 ms PCM 音频包、独立 WASAPI 播放线程、自适应缓冲、时钟漂移补偿、静音与输出设备恢复。Mac 需要可用的音频输出设备，配置与验证见[音频说明](../audio.md)。
- 视频调度：Mac 编码 worker 使用事件唤醒；Windows worker 使用可取消的高精度等待。继续保持最新帧、有界队列和单帧编码提交策略。
- 诊断：补齐捕获、编码、发送接受、接收、解码、呈现与音频阶段数据；新增独立 ScreenCaptureKit 捕获探针及 DisplayLink 动画源。
- 回归可靠性：日志关闭测试先确认记录入队再检查落盘，保留生产日志的 try-lock 和有界丢弃策略。

这不是稳定 60 FPS 的验收。参考 RTX 3060 / macOS 15.8.1 环境在当前负载下，独立捕获约 51–55 Complete/秒；提高请求频率、扩大队列、切换像素格式及降低输出分辨率未证明持续稳定 60 FPS。完整对照见[FPS 稳定性记录](../fps-stability-2026-10-12.md)，调度数据见[低延迟优化记录](../latency-optimization-2026-10-11.md)。

音频捕获至 Windows 播放线程的短时检查通过，但可听音质和捕获至扬声器的端到端延迟尚未验收。Windows ARM64 与 Apple Silicon 的实体配对会话仍未验证；CI 的架构、打包和离线测试不替代这些检查。

## English

This release adds Mac system audio, video worker scheduling improvements and stage diagnostics to the packaged apps. Update both endpoints.

- System audio uses 5 ms PCM packets, an independent WASAPI worker, adaptive buffering, clock-drift correction, mute and output-device recovery. The Mac needs a usable output device; see the [audio guide](../audio.md).
- The Mac encoder worker uses event notifications. The Windows worker uses cancellable high-resolution waits. Latest-frame, bounded-queue and single-frame encoding policies remain in place.
- Diagnostics cover capture, encoding, send acceptance, receive, decode, presentation and audio. Source includes a metadata-only ScreenCaptureKit probe and display-linked animation fixtures.
- Logger shutdown regression checks confirm queue admission before testing persistence; production logging retains its try-lock and bounded-drop policy.

Stable 60 FPS is still unverified. The reference RTX 3060 / macOS 15.8.1 setup measured approximately 51–55 Complete events per second in independent capture tests under the observed load. The comparisons do not establish a unique cause or a causal performance improvement. See the [FPS experiments](../fps-stability-2026-10-12.md) and [scheduling measurements](../latency-optimization-2026-10-11.md).

Short capture-to-Windows audio checks passed; listening quality and capture-to-speaker latency remain unmeasured. Physical Windows ARM64 and Apple Silicon paired sessions remain unvalidated.

## Packages

Choose the ZIP for your OS and CPU: Windows x64 / ARM64 or macOS Intel x64 / Apple Silicon ARM64. Verify the ZIP against `SHA256SUMS.txt`.

Windows binaries are not Authenticode-signed. Mac packages are ad-hoc-signed without Developer ID signing or notarization; macOS may request permission approval after replacement. Existing configuration paths and pairing formats remain compatible. Credentials, logs, development keys, BlackHole and the experimental NVIDIA driver are not included.
